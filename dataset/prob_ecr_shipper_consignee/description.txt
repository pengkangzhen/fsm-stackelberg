A container liner company needs to optimize its empty container repositioning network. The network consists of four types of nodes: seaports, dry ports, consignees, and shippers. Empty containers can be repositioned between any pair of nodes using available transport modes (rail, truck, barge), subject to transport availability constraints defined by $\delta_{ijk}$, where $\delta_{ijk}=1$ if transport mode $k$ is available on arc $(i,j)$. However, repositioning from consignees to shippers is only allowed if they share the same dry port hinterland coverage. Let $\alpha_{jp}=1$ if consignee $p$ is within the hinterland of dry port $j$, and $\beta_{jq}=1$ if shipper $q$ is within the hinterland of dry port $j$. Street-Turn repositioning is permitted only if there exists a shared dry port$.

Let $N^{\text{supply}}$ denote the set of supply nodes (seaports, dry ports, and consignees) and $N^{\text{demand}}$ denote the set of demand nodes (seaports, dry ports, and shippers). Each supply node $i \in N^{\text{supply}}$ has empty container surplus $S_i^t$ in period $t$; each demand node $j \in N^{\text{demand}}$ has empty container demand $D_j^t$ in period $t$. Consignees generate surplus from unpacking import containers; seaports and dry ports have predefined net supply/demand values. Seaports and dry ports have storage capacity limits $\bar{U}_i$. Let $\tau_{ijk}$ denote the transit time (in periods) from node $i$ to node $j$ using transport mode $k$. For inter-seaport barge transport, $\tau=1$; for all other routes, $\tau=0$.

Empty container repositioning supports three transport modes: rail, truck, and barge. The total repositioning volume between two nodes is the sum across all transport modes.

The objective is to minimize total operating costs over the planning horizon, including: (1) transportation costs for repositioning between any node pair, (2) holding costs at storage nodes (seaports and dry ports), and (3) renting costs when containers are rented to meet demand. Formulate a multi-period network flow optimization model and output the MILP formulation.
