# ECR 库存动态与时序规则

## 节点堆存能力

- **海港**和**陆港**具备空箱堆存能力，可持有库存、租入空箱
- **收货人**和**发货人**不具备堆存能力，当期空箱必须全部发出或全部满足

## 周期内事件顺序

每个周期内的事件执行顺序为：

1. **期初库存结转**：继承上一周期末的库存作为本周期初的初始库存
2. **在途库存到达**：处理上一周期发出的调运到达，更新各节点库存状态
3. **重箱转化**：将上一周期到达的重箱转化为本周期的空箱供给
4. **调运与租箱决策**：进行本周期的调运和租箱决策，优化空箱配置

简记：**库存继承 → 在途到达 → 重箱转化 → 调运决策**

## 库存动态方程

### 海港节点库存平衡

海港周期末库存 = 期初库存 + 所有调入量 + 空箱供给 + 租箱量 - 调出量 - 空箱需求

### 陆港节点库存平衡

陆港周期末库存 = 期初库存 + 所有调入量 + 空箱供给 + 租箱量 - 调出量 - 空箱需求

### 收货人节点流量平衡

收货人仅输出空箱，无库存：**所有有效流出弧上的调出量之和** = 空箱供给量

### 发货人节点流量平衡

发货人仅接收空箱，无库存：**所有有效流入弧上的调入量之和** = 空箱需求量

## 存储节点与本地供需的耦合规则

对于具备堆存能力的节点（海港、陆港），若该节点本身有空箱供给，则库存平衡必须显式吸收该节点的本地供给；若该节点本身有空箱需求，则必须显式吸收本地需求。

等价地，库存演化应满足：

`I_i^t = I_i^{t-1} + arrivals + local_supply + rentals - outflow - local_demand`

其中：

- `local_supply` 对应节点 `i` 在时期 `t` 的空箱供给 `S_i^t`
- `local_demand` 对应节点 `i` 在时期 `t` 的空箱需求 `D_i^t`

## 堆存能力约束

海港和陆港的周期末库存不能超过其堆存能力上限。库存以标准集装箱（TEU）为最小计量单位，不可拆分。

## 时序延迟规则

### 海港间调运延迟

由于国际海运班轮具有固定周期性（通常为每周一班），海港间的空箱调运需经历若干周期的在途时间。

即：某周期从海港发出的空箱，将在若干周期后到达目的海港。

### 内陆调运即时性

海港与陆港间、陆港间、腹地内收发货人间的调运均可于本周期内完成，体现高效的内陆集疏运体系。

## 到达边界与零时滞弧

- 当 `tau_{ijk} = 0` 时，同期到达是合法的，模型必须能够表示这类到达。
- 当计算到达来源时期 `t - tau_{ijk}` 时，若结果小于 1，则视为规划期开始前，不计入到达量。
- 不允许从规划期开始前虚构到达，但允许对显式给定的零时滞有效弧进行同期到达核算。

## 稀疏弧参数一致性

运输成本与运输时间参数仅在有效运输弧上有定义，建模时应围绕有效弧集定义运输与到达。

## 供需转化机制

### 空箱供给来源

- **海港**：上一周期抵达海港的进口重箱于本周期转化为空箱供给
- **陆港**：上一周期抵达陆港的进口重箱于本周期转化为空箱供给
- **收货人**：上一周期抵达收货人的进口重箱于本周期转化为空箱供给

### 空箱需求来源

- **海港/陆港**：出口重箱装载需求
- **发货人**：货物装箱需求

## 约束类型推理规则

不同节点类型虽然都可能有供给或需求，但 supply/demand 在不同节点类型下的**建模方式完全不同**。必须根据节点的堆存能力推断正确的约束形式：

### 规则 1：无堆存能力的节点 → 流量平衡等式

收货人和发货人**不具备堆存能力**，没有库存变量 `I[i,t]`。因此它们的 supply/demand 不能进入库存递推，必须写成**当期流量平衡等式**：

- **收货人**（纯供给）：`Σ outflow[p,j,k,t] = supply[p,t]`（所有有效流出弧的流出量之和 = 本期供给）
- **发货人**（纯需求）：`Σ inflow[i,q,k,t] = demand[q,t]`（所有有效流入弧的流入量之和 = 本期需求）

### 规则 2：有堆存能力的节点 → 库存平衡递推

海港和陆港具备堆存能力，拥有库存变量 `I[i,t]`。它们的 supply/demand 进入库存平衡方程：

- `I[i,t] = I[i,t-1] + inflow + local_supply + rental - outflow - local_demand`

**关键区分**：同一份供给数据，在收货人处是等式约束的右端，在存储节点处是库存方程的一个参数。

### 规则 3：约束覆盖完整性

每个节点类型都必须有完整的流量守恒约束：存储节点需要库存平衡，收货人需要流出等式，发货人需要流入等式。
