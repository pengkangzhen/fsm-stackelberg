# ECR 节点类型知识

## 海港（Seaport）

- **功能定位**：国际运输枢纽节点，连接国际航线与内陆物流网络
- **能力**：具备空箱堆存能力
- **属性**：
  - 堆存能力上限
  - 单位周期库存持有成本
  - 单位租箱成本

## 陆港（Dry Port）

- **功能定位**：内陆物流枢纽节点，连接海港与腹地客户
- **能力**：具备空箱堆存能力
- **属性**：
  - 堆存能力上限
  - 单位周期库存持有成本
  - 单位租箱成本
- **腹地辐射**：陆港与腹地内的收货人、发货人存在归属关系

## 收货人（Consignee）

- **功能定位**：纯供给型节点，拆空进口重箱后产生空箱盈余
- **能力约束**：
  - 不具备空箱接收能力
  - 不具备空箱堆存能力
- **调运规则**：拆箱后产生的空箱必须全部调出，总调出量等于本期空箱供给量

## 发货人（Shipper）

- **功能定位**：纯需求型节点，需要空箱满足出口装箱需求
- **能力约束**：
  - 不具备空箱输出能力
  - 不具备空箱堆存能力
- **调运规则**：须从外部获取空箱，总流入量等于本期需求量

## 节点类型对比

| 节点类型 | 供给/需求 | 堆存能力 | 接收能力 | 输出能力 |
|---------|----------|---------|---------|---------|
| 海港 | 混合 | 有 | 有 | 有 |
| 陆港 | 混合 | 有 | 有 | 有 |
| 收货人 | 纯供给 | 无 | 无 | 有 |
| 发货人 | 纯需求 | 无 | 有 | 无 |
